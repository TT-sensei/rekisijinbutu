# れきし探偵団

小学校6年生を主な対象に、歴史上の人物や各時代のくらし・文化・遺跡を4択クイズで学ぶ、GitHub Pages向けのWeb教材です。進捗、正答率、XPを端末内に保存し、繰り返し学習できます。

## 学習モード

- **人物から学ぶ**: 人物を時代分類から選び、人物ごとに用意された問題から5問に挑戦します。全問正解で人物を解放し、間違えた問題だけを復習できます。既存の人物と問題を削除せず維持しています。
- **時代から学ぶ**: 縄文から戦後までの単元を時代順に選び、くらし・文化・遺跡などを学びます。各回は単元内から重複なしで最大5問を出題し、解答後に解説を表示します。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面、スタイル、画面遷移、クイズ・保存処理 |
| `people.js` | 人物マスター |
| `questions.js` | 人物クイズ |
| `eras.js` | 時代単元マスターと表示順 (`order`) |
| `eraQuestions.js` | 時代クイズ |
| `scripts/validate-data.js` | 問題データの自動整合性チェック |

外部ビルドやサーバー側処理は不要です。4つのデータファイルは `index.html` より先に読み込みます。

## データを追加する方法

### 人物を追加する

1. `people.js` の `PEOPLE` に、重複しない `id` と `name`, `kana`, `era`, `emoji`, `hint` を持つ人物を追加します。
2. 既存の時代分類名を使うか、新分類の表示期間を `index.html` の `ERA_PERIOD` に追加します。
3. 下記の人物問題を5問用意し、検証スクリプトを実行します。

### 人物問題を追加する

`questions.js` の `QUESTIONS` に `{ personId, q, choices, answer, explanation }` を追加します。`personId` は `PEOPLE` に存在するID、`choices` は必ず4つ、`answer` は0〜3の正解位置です。人物の通常クイズは5問を前提にするため、各人物について5問を維持してください。

### 時代単元を追加する

1. `eras.js` の `HISTORY_ERAS` に、重複しない `id` と `era`, `name`, `subtitle`, `period`, `emoji`, `description`, `available`, `order` を追加します。
2. 分割単元を含め、`order` が実際の学習順になるようにします。
3. 問題が未準備なら `available: false` とし、カードに「準備中」を表示します。

### 時代問題を追加する

`eraQuestions.js` の `ERA_QUESTIONS` に `{ eraId, category, q, choices, answer, explanation }` を追加します。`eraId` は `HISTORY_ERAS` に存在するIDを指定します。単元内から最大5問を重複なしで選ぶため、十分なバリエーションを用意してください。5問未満でもある問題だけで動作し、0問なら安全に開始を中止します。

## 保存データ

`localStorage` のキー **`rekiDanSave_v3`** を使用します。XP、レベル、ログイン情報、人物別の解放・クリア回数・正答数・回答数、時代単元別の最高得点・挑戦回数・マスター状態を保存します。

読み込み時は、保存データなし、`people` / `eras` の片方のみ、一部IDのみ、旧形式で `correct` / `total` がない場合を既定値で補完します。未知の既存キーや人物記録は削除しません。不正JSONはサイトを停止させず、安全な初期値をメモリ上で使います。公開後に保存キーや既存IDを安易に変更しないでください。

## データ検証

```bash
node scripts/validate-data.js
```

人物・単元IDの重複、存在しない参照ID、4択でない問題、範囲外の正解、空の問題文・解説、同一問題文、人物別・単元別問題数、正解番号分布を確認します。エラーを解消してから公開してください。正解位置の軽い偏りや意図した類似問題は警告として内容を人が確認します。

## GitHub Pagesで公開する

1. 変更を既定ブランチへpushします。
2. GitHubリポジトリの **Settings → Pages** を開きます。
3. **Build and deployment** で **Deploy from a branch** を選び、公開ブランチと `/ (root)` を指定して保存します。
4. 表示されたURLでスマートフォンとPCの画面遷移、クイズ、保存を確認します。

相対パスだけで構成されているため、リポジトリ配下のPagesでも動作します。Google Fontsが取得できない環境では端末の代替フォントで表示されますが、クイズ機能には影響しません。

## 問題作成時の注意事項

- 小学校6年生が理解できる短い文にし、難しい漢字には必要に応じて読み仮名を付けます。
- 固有名詞、制度名、読み仮名の表記を既存問題と統一します。
- 選択肢に正解が複数ないこと、正解位置が一方向へ偏らないことを確認します。
- 学説が分かれる事柄は「〜と考えられている」「いくつかの説がある」と表現します。
- 戦争、災害、差別などを軽いゲーム表現で扱わず、事実と人々への影響を丁寧に説明します。
- 解説は正解の理由が分かる長さにし、問題文の単なる繰り返しにしません。
- 人物問題と時代問題の目的を分け、同じ設問ばかりにしません。
- 追加後は検証スクリプト、ブラウザの全導線、コンソールを確認し、既存の人物・問題・保存IDを削除していないことを差分で確認します。
